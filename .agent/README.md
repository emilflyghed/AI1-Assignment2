# .agent/ — Session Memory

Authoritative project context for the agent. Read all files here at the start of every session before taking action. Update continuously during work, not only at the end.

## Files
- `state.md` — current project state, in-progress work, next steps.
- `decisions.md` — architectural/design decisions with reasoning.
- `debugging.md` — bugs encountered, root causes, fixes.
- `gotchas.md` — environment quirks and non-obvious behaviors.
- `common-mistakes.mdc` — avoidable-mistakes log; one line per mistake.
