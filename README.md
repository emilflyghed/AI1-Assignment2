# AI1-Assignment2

This repository is organized by assignment part. Each part folder is intended
to be transferable on its own.

## Structure

- `part_1/` - compact single-file Part 1 ReAct agent with Docker support.
- `part_1_test/` - previous expanded/testable Part 1 implementation, kept for
  reference while the simple submission version is developed.
- `assignment_instructions.md` - assignment-level instructions for all parts.
- `.agent/` - shared project/session notes that may be useful across parts.

Local secrets such as `.env` stay at the assignment root and are ignored by git.
